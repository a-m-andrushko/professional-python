What is a Python module?

A module is a single unit of code execution.



What is a Python package?

A package is a specialised module that serves as a container for other modules.

To be a traditional package, it must contain a \_\_init\_\_.py file (or act as a namespace package).



Why might splitting code across multiple files be better than writing everything in main.py?

It increases code readability and makes it easier to move through the project.



What role does \_\_init\_\_.py appear to play?

\_\_init\_\_.py is a special file used to mark a directory as a regular Python package.

When you place this file inside a folder, you tell the Python interpreter that the folder contains modules and sub-packages that can be imported.
